An independent lab in London, Ontario. We build open-source software for the agent era, and
sell the expertise that built it. Products first, services second, research third.

## Products

| | |
|---|---|
| **[Ninebrains](https://github.com/Advance-Labs/ninebrains)** | Desktop app that runs several Claude Code and Codex agents at once, each in its own git worktree, terminal and browser. A central Brain hands out the work, and a second agent has to prove it before it counts as done. Early releases for macOS, Windows and Linux; builds are not yet code-signed. Apache-2.0. |
| **[runs-on.dev](https://github.com/zordhalo/runs-on.dev)** | Free subdomains for developer projects. Claiming `yourname.runs-on.dev` writes one file to a public repository, which is also the registry's database. AGPL-3.0. |
| **[AEO Toolkit](https://github.com/Advance-Labs/aeo-toolkit)** | Open-source answer-engine optimization tools. A free Chrome extension audits any page against 40 checks, entirely in the browser; three MCP servers expose the same instruments to any MCP client; the same engine plus 14 E-E-A-T checks runs our 54-rule paid audit. Apache-2.0. |

## Services

Fixed-price [AI-visibility (AEO) audits and build sprints](https://advancelabs.dev/services),
run on the same open-source engine, so a client can read the rule that scored them.

## Research

- [urban-drone-autonomy](https://github.com/Advance-Labs/urban-drone-autonomy): sim-first mission autonomy for a multirotor, verified against PX4 SITL. Apache-2.0.
- [quantum-hybrid-research](https://github.com/Advance-Labs/quantum-hybrid-research): feasibility studies where quantum meets classical computing. MIT.
